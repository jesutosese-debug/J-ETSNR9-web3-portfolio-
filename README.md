# JØETSNR9 — Web3 Portfolio

A responsive, dark futuristic personal portfolio for a Web3 project/community operator.

## Files
- `index.html` — page content
- `styles.css` — layout, colors, responsive styling and animation
- `script.js` — mobile navigation and current year

## Before publishing
1. Open `index.html`.
2. Find `YOUR_TELEGRAM_USERNAME` and replace it with your Telegram username (without `@`).
3. Find `YOUR_EMAIL@example.com` and replace it with the email address you want public.
4. Review the project descriptions and remove or edit anything that does not accurately describe your contribution.
5. Optional: add verified project URLs and specific results when you have permission to publish them.

## Run locally
Open `index.html` in a browser. No build tools or package installation are required.

## Deploy to Vercel
1. Create a new GitHub repository named `joetsnr9-web3-portfolio`.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository root.
3. Sign in to Vercel and choose **Add New → Project**.
4. Import `joetsnr9-web3-portfolio` from GitHub.
5. Keep the framework preset as **Other**. Leave the build command and output directory blank.
6. Click **Deploy**.

This is a static site, so no build command is needed.
